# Rebecca change scope

- Apply only features and appearance changes the owner explicitly requests.
- Do not bundle suggestions, unrelated refactors, theme changes or core upgrades.
- Preserve the official Hiddify connection engine, import formats, routing and settings unless a requested change needs otherwise.
- Verify modified behaviors and report actual checks and device-test limits. Do not promise zero bugs.
- Keep the application ID and existing owner signing key stable for updates. Never commit credentials or signing material.
